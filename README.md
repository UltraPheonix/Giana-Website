# Giana Praise Website

This is a simple one-page church singer website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` contains the page structure and content.
- `styles.css` controls the layout, colors, typography, and responsiveness.
- `script.js` adds interactivity like the mobile menu, reveal animations, and form feedback.

## How To Customize It

1. Replace the hero text with the singer's real name, tagline, and booking details.
2. Swap the placeholder portrait background in `styles.css` with a real photo.
3. Add an embedded YouTube video or audio player in the music section.
4. Update the event dates, testimonials, and contact information.
5. Connect the contact form to a real backend or form service when you're ready to collect bookings.

## Why It Feels Modern

- Strong typography with a serif headline and clean sans-serif body text.
- Soft gradients and glass-like cards for depth.
- Responsive layout that stacks neatly on smaller screens.
- Small motion effects that reveal content as the user scrolls.

## How The JavaScript Works

- The menu button toggles the mobile navigation.
- The year in the footer updates automatically.
- The reveal observer animates sections as they enter the viewport.
- The form shows a friendly confirmation message instead of reloading the page.

## To Make It Your Own

If you want, the next step can be turning this into a multi-page site with pages like About, Music, Events, and Contact.
